# About

I’m Reza Rasouli. I’ve been a software engineer for about a some years now, which mostly means I process large jugs of coffee and fuel them into solving scalable and real-time systems. By day, I play nicely with others, write backend code, and mentor time to time. By night, I shed my corporate skin to willingly suffer through learning about concurrency, database internals, and low-level programming mostly in Java, Kotlin and Rust. If you love talking about distributed systems or JVM garbage collection, we’ll get along great. Hit me up in one of following places:
